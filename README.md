# CV

Лендинг-резюме Никиты Колосова, ведущего Go-разработчика.

Один статический файл `index.html` без сборки и зависимостей. Блок опыта сделан в виде трейса: каждая компания — span на шкале 2013–2026, клик раскрывает подробности. Длительность текущей работы пересчитывается в браузере.

## Публикация

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `master`, папка `/ (root)`. Сайт откроется по адресу https://nkolosov.github.io/cv/.

## Правка

Опыт описан прямо в разметке. Положение полосы задаётся в месяцах от августа 2013: `style="--s:<начало>;--e:<конец>"`.
